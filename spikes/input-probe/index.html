Transmitter Probe

Feasibility check for the RC heli sim: can this phone's browser read a DX6i through the wireless USB dongle, and can it do Cardboard VR?

Before you start

  1. Bind the DX6i to the dongle (hold the dongle's bind button while plugging it in, then bind the radio as usual).
  2. Plug the dongle into the phone with the USB-C OTG adapter. Open this page in Chrome.
  3. Wiggle every stick and flip every switch. Browsers hide controllers until one moves.
  4. Move each stick to all four corners so the ranges fill in, then tap Copy report and paste it back to Claude.

This device

This page is running inside an embedded viewer, which can block motion sensors and WebXR. A red result for those two may be the viewer, not the phone. Open the file from the repo directly in Chrome to be sure.
